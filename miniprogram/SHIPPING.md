# 上架 Checklist — 微信小游戏 + 抖音小游戏

Time Dodge 小游戏（`miniprogram/`）从「代码就绪」到「商店上线」的完整步骤。
代码已按官方文档实现并做过无头验证（引擎不变量 + 分包启动接线，`node
miniprogram/test/run.js`），但**未在微信/抖音开发者工具或真机上跑过**——本清单
覆盖那段需要你在本机 + 平台后台完成的工作。

图例：🟢 已在仓库就绪 ｜ 🟡 需你填占位符 ｜ 🔴 需平台后台/真机

## 1. 组装工程（每次改 `boot/` 或 `shared/` 后都要跑）

```bash
cd miniprogram
sh prepare.sh          # 把 boot/ 和 shared/ 组装进 wechat/ 与 douyin/ 根目录
node test/run.js       # 28 项应全绿
```

`prepare.sh` 会生成 `wechat/boot/`、`wechat/engine/shared/`（抖音同理）——这些是
**生成物**，已被 `.gitignore` 忽略，不要手改。真正的源在 `boot/` 和 `shared/`。🟢

---

## 2. 填占位符 🟡

| 文件 | 占位符 | 换成 |
|------|--------|------|
| `wechat/project.config.json` | `"appid": "wxYOURAPPIDHERE0000"` | 你的微信小游戏 AppID |
| `douyin/project.config.json` | `"appid"`（占位）| 你的抖音小游戏 AppID |
| `wechat/adapter.js` | `adUnitId: 'adunit-XXXXXXXXXXXXXXXX'` | 微信激励视频广告位 id（见 §4）|
| `douyin/adapter.js` | `adUnitId: 'YOUR_DOUYIN_AD_UNIT_ID'` | 抖音激励视频广告位 id（见 §4）|

搜 `TODO(ship)` 可定位广告位两处。

---

## 3. 导入 DevTools 并联调

### 微信
1. 微信开发者工具 → **导入项目** → 目录选 `miniprogram/wechat` → 类型 **小游戏**。
2. AppID 填你的（或先用工具的「测试号」跑通）。
3. 编译预览：应先看到**深空加载页 + 进度条**（主包启动器），进度到 100% 后进入
   游戏——这就是**分包在真实基座下的加载路径**（DevTools 里可在「详情 → 本地设置」
   或「分包」面板看到 `engine` 子包）。
4. 真机预览：点「预览」扫码，在手机上验证下面 §5 的清单。

### 抖音
1. 抖音开发者工具 → **导入项目** → 目录选 `miniprogram/douyin` → 类型 **小游戏**。
2. AppID 填你的抖音小游戏 id。
3. 同样先加载页后进游戏；真机走「真机调试 / 预览」。

> `require` 不能跨出打开的根目录，且两平台用同名 `game.json`/`project.config.json`，
> 所以 `wechat/` 与 `douyin/` 各是自包含的根，`shared/` 不共享——由 `prepare.sh`
> 分别拷入。这点已在 README「分包架构」写明。🟢

## 4. 激励视频广告位 🔴

ABSORB 模式「取消这次撞击 YES」触发激励视频（看完才免除扣血），需要真实广告位：

- **微信**：mp.weixin.qq.com → 流量主（需先满足开通条件）→ 新建**激励视频**广告位 →
  拿 `adunit-xxxxxxxx` 填进 `wechat/adapter.js`。
- **抖音**：抖音开放平台 → 变现/广告 → 新建**激励视频** → 广告位 id 填进
  `douyin/adapter.js`。

未配广告位时代码会「直接免除」（DevTools 无广告组件的兜底），仅供联调；上线务必换成
真实 id，否则审核/变现不通过。

## 5. 真机验收清单 🔴（DevTools 模拟器不能替代）

- [ ] **触控坐标**：拖动手感正确，光球随手指 delta ×1.5 移动，不被手指遮住。
- [ ] **画布尺寸 / 刘海屏**：`adapter.js` 用 `windowWidth/Height` 逻辑像素铺满；确认
      在刘海屏/灵动岛机型不裁切、不拉伸。
- [ ] **持有=时间流动 / 松手=冻结** 三种模式表现正确。
- [ ] **存档**：`timedodge_best` / `td_absorb_best` / `td_lv<i>_stars` 等 KV 在
      `wx/tt.getStorageSync` 下重启后仍在。
- [ ] **激励视频生命周期**：看完 → 免扣血；中途退出/报错 → 正常扣 25%。
- [ ] **帧率**：ProMotion 机型是否跑满；软件渲染/低端机是否可接受。
- [ ] **加载页**：弱网下进度条平滑推进，子包加载失败时显示「LOAD FAILED — RETRY」。

## 6. 商店素材与元信息 🔴

两个平台各需：应用**图标**、**封面图/横版竖版截图**、名称、简介、**类目**（休闲/
益智）、隐私政策、（中国）ICP/实名与内容合规信息。抖音另需短视频/直播引流素材可选。

---

## 7. 提交审核

- 微信：开发者工具「上传」→ mp 后台「版本管理」提交审核 → 通过后发布。
- 抖音：开发者工具「上传」→ 开放平台提交审核 → 通过后发布。
- 含激励视频广告的，会一并走**变现合规**审核；确保广告位与内容分级一致。

- 一个引擎 demo：九项能力九个小玩具，每个都能一键压测到掉帧为止，成绩就存在游戏里。浏览器点开即玩。
- 我们把引擎的每个 API 做成了一个可以玩的东西——然后给每个 API 配了一个"跑到掉帧为止"的按钮。

## 短文案（100 字内，社媒帖）

**帖 A（能力向）**
点开浏览器，你会看到 9 张卡片：多点触控、骨骼动画、粒子、tilemap、摄像机、混音台、存档、图集动画、手感实验室。每张卡片是一个引擎 API 的可玩演示，右上角的 BENCH 按钮会当着你的面加压到掉帧，然后把分数存进游戏存档。没有宣传片剪辑，全是实时渲染。

**帖 B（AIGC 向）**
这个 demo 里没有一张人画的图：金币图集、地形贴图、机器人部件是 Seedream 生成的，BGM 是 Lyria 2 生成的，机器人的骨骼动画是一份 47 行的手写 JSON。美术管线的"编辑器"是一个 agent——这不是概念稿，是你现在就能玩到的东西。

**帖 C（工程向）**
一份 Lua 代码，macOS / iOS / Web 三端逐字节相同地跑。浏览器版不是移植：因为 wasm 没有 C 工具链，我们直接换了一个纯 Rust 的 Lua VM，而脚本一行没改——命令队列架构的红利。demo 的 9 个站全部接入无头测试，13 万条断言天天在 CI 里跑它。

## 长文案（上架页 / 博客导语）

游戏引擎的宣传页都长一个样：一排 feature 图标，一段"强大而灵活"的形容词。我们决定换个做法——把 feature list 本身做成游戏。

Engine Showcase 是 hollowlullaby 引擎的自证明 demo。打开它，你会进到一个 3×3 的能力矩阵：每张卡片对应引擎脚本桥的一组 API，点进去不是文档，是一个立刻能上手的小玩具——手指作画的地形编辑器、能真拖的混音台、头会看向你手指的骨骼机器人、点哪炸哪的烟花。

每个站的右上角都有一个 BENCH 按钮。按下去，引擎开始给自己加压：更多的精灵、更多的粒子、更大的地图重刷、更多的骨骼角色——直到帧时间守不住 45fps 预算，把最后守住的档位定格成分数，存进游戏存档。你手机的九项能力跑分，就挂在存档站的墙上。

顺便说一句：这个 demo 里的每一张图、每一段音乐，都来自 AIGC 管线（Floniks：Seedream 4 出图，Lyria 2 作曲），机器人的动画是一份手写 JSON。引擎没有编辑器——因为它的编辑器是数据和 agent。

浏览器点开即玩：maweis.com/rust_bevy_lua_game

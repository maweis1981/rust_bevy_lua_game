## 关键思路(为什么这么做)

1. **玩法即调研产物**:用户不给规则书。从截图猜玩法族 → 搜索验证规则细节 → 写成 Lua 不变量(每行/列/色恰一、不相邻),测试即规则文档。
2. **唯一解是硬标准**:v1 盲随机重摇在 8×8 上找不到唯一解棋盘(首关实测 **237 个解**)。改用**爬山精炼**:随机初始 → 数解个数 → 局部扰动使解数单调下降 → 收敛到 1。测试断言"每关唯一解",这个 bug 是被测试当场抓住的。
3. **视频还原靠关键帧**:对照视频抽帧核对 UI 元素清单与布局比例,而不是凭印象;还原度反馈也全部用截图对照驱动。
4. **白板 bug 是引擎课**:`spawn` 后同帧 `set_color/set_size` 被静默丢弃(Commands 未 apply,Query 查不到新实体)→ 引擎在 apply_lua 加 `commands.entity(e).entry::<T>().and_modify()` 兜底(#9,`7fb51f5`)。此修复让所有游戏受益。

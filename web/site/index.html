这是什么

一个开源的 2D 小游戏引擎 + 脚手架（仓库名 rust_bevy_lua_game）。 它相信 AI 时代应该有 AI 时代的游戏开发方式：

ARCHITECTURE

Rust 管引擎，Lua 管玩法

Bevy 0.19 ECS 内核负责渲染 / 音频 / 跨平台；玩法全在 Lua 5.4 里，桌面端保存即热重载。Lua 从不直接触碰 ECS——命令队列桥保证两层可以独立演化。

CROSS-PLATFORM

一份代码，三个平台

同一份 Rust crate 编成桌面二进制、iOS 静态库（120Hz ProMotion）和 WASM。Web 端用纯 Rust 的 Lua VM（ottavino），脚本与原生逐字节相同。

AI-NATIVE

为 agent 设计，没有编辑器

架构契约写在 CLAUDE.md，关卡是数据、素材是 Floniks AIGC 管线（文生图 / 图生图 / TTS / 文生音乐），13 万+ 条无头测试断言让 agent 敢自主迭代。

游戏作品

全部游戏在同一个 WASM 包里——点任意一个进入试玩，然后在主菜单选择对应卡片。 每款游戏都是引擎的一次真实验收，玩法逻辑各是一个 Lua 文件。
